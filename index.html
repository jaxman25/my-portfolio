About Me

I Build Practical Web Applications for Real Business Needs

I build database-driven web applications for businesses and organizations — systems that handle real operational work like restaurant orders, student billing, and patient records, where reliable data handling and clear interfaces matter.

My stack is practical and focused: Python and Flask for backend logic, JavaScript for interactive frontends, and PostgreSQL or MySQL for structured data. I work through the full development cycle — from database schema design through frontend implementation and testing.

Alongside development, I take on graphic design work — branding, posters, and promotional materials. It's a secondary skill that supports my development work by keeping me focused on clear, usable interfaces.
