## 🚀 Features

- **Dark / Light Mode** — Toggle between themes; respects your system preference on first visit
- **Fully Responsive** — Optimized layout for desktop, tablet, and mobile devices
- **Scroll Reveal Animations** — Elements animate in as you scroll using IntersectionObserver
- **Typewriter Effect** — Animated tagline in the hero section
- **Case Study Modals** — Detailed project breakdowns with full-screen image lightbox
- **Skill Progress Bars** — Animated progress indicators that fill on scroll
- **Stats Counter** — Animated number counters for projects, technologies, and designs
- **Contact Form** — Sends messages via Formspree integration
- **Floating Hero Image** — Profile photo with glowing border, spinning ring, and availability badge

## 💻 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or package manager required

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/jaxman25/my-portfolio.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd my-portfolio
   ```

3. **Open in your browser**

   ```bash
   # macOS
   open index.html

   # Windows
   start index.html

   # Linux
   xdg-open index.html
   ```

That's it — no server, no dependencies, no build step. Just open `index.html`.
